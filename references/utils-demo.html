Format an amount FormattableNumber

String-based, no floating-point loss. Grouping uses a narrow no-break space and only appears past 4 integer digits

 
new FormattableNumber('1234567.891234')
    .toString({ maxDecimals: 4, useGrouping: true })
// '1 234 567.8912' (U+202F separators)

Validate an address ValidationUtils

NQ prefix, 36 chars ignoring spaces, 32-char alphabet without I, O, W, Z, and an IBAN mod-97 checksum

 
ValidationUtils.isValidAddress(address)  // boolean
ValidationUtils.isUserFriendlyAddress(address)  // throws the reason
ValidationUtils.NIMIQ_ALPHABET  // '0123456789ABCDEFGHJKLMNPQRSTUVXY'

Build a request link createRequestLink

NIM amounts go in as luna (1 NIM = 100 000 luna), the message tops out at 64 UTF-8 bytes

 
createRequestLink(recipient, {
    currency: Currency.NIM,
    amount: 12.5e5,  // luna
    message: 'Coffee',
    basePath: 'https://wallet.nimiq.com',
})

Currency info lookup CurrencyInfo

Symbol, name, decimals and locale for any 3-letter fiat code, resolved through Intl with Nimiq's correction tables

symbol
name
decimals
locale
const c = new CurrencyInfo('EUR');
c.symbol;    // '€'
c.name;      // 'Euro'
c.decimals;  // 2

Copy to clipboard Clipboard.copy

Synchronous textarea and execCommand copy that restores your focus and selection afterwards, the same helper behind the wallet's copy buttons

Clipboard.copy(text)  // returns true on success; wallet shows 'Copied' for 800 ms
